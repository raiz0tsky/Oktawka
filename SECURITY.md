# Security

Oktawka is a development preview. Security fixes target the latest source on `main`; older review APKs may require replacement.

## Report a vulnerability

Use this repository’s **Security → Report a vulnerability** option when available. If private reporting is unavailable, open an issue asking for a private reporting channel without including exploit details, credentials or personal data.

Never post provider keys, OAuth tokens, signed stream URLs, browser-storage exports or signing keys in an issue. Redact logs and screenshots. If a credential was exposed, revoke it with its provider immediately; deleting a comment or commit does not revoke it.

Include the affected revision, platform, reproduction steps and likely impact in the private report. There is no guaranteed response time or bug-bounty program.
