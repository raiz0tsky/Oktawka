# Screenshots

Every image here is a real capture of the running app. Nothing is mocked up.

- **Source:** the current web build (`node scripts/build-worker.mjs`), served locally and captured with headless Chromium on 2026-11-26.
- **Viewports:** phone 390 × 844 at 2×, desktop 1440 × 900 at 1×.
- **Audio while capturing:** a generated 24-bit / 96 kHz FLAC test tone (440 Hz), imported as a local file, and the Radio Paradise main-mix live stream. The `LOSSLESS · 24-BIT · 96 kHz` badge was read from that file's real header. The radio badge says "bits unverified" because the live stream was not verified.
- **Composites:** `hero.jpg` and `themes.png` arrange these same captures on a plain background. Nothing inside a capture was edited.
- **Not shown:** these are not Android device captures, so system bars and cutouts are absent. Catalog album artwork is left out because it belongs to its rights holders.
